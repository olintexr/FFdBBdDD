# Tarea 01 — Capítulo 1: Introducción a los sistemas de bases de datos

> **Aviso:** Cualquier uso de herramientas de inteligencia artificial para realizar esta tarea será penalizado.

Responda las siguientes preguntas con claridad y sustente sus respuestas cuando corresponda.

1. **Explique qué es una base de datos y describa sus tres características fundamentales: persistencia, consistencia y accesibilidad.** Mencione cuatro procesos o aplicaciones que pueden apoyarse en una base de datos.

2. **Explique la diferencia entre los lenguajes procedimentales y los no procedimentales.** Use los ejemplos del resumen para indicar qué debe especificar el programador en cada caso.

3. **Describa las tres capas de un sistema de información: base de datos, reglas de negocio y aplicaciones.** Explique cómo se relacionan y por qué la base de datos puede considerarse una fuente única de verdad.

4. **Explique los niveles físico, lógico y de vistas de abstracción de datos.** ¿Cómo pueden las vistas ocultar información o simplificar el acceso para distintos usuarios?

5. **Describa la función de los lenguajes DDL, DML y TCL.** Dé un ejemplo de una operación que corresponda a cada uno y explique qué tipo de trabajo permite realizar.

6. **Explique cómo la separación entre los niveles de abstracción permite la independencia de datos.** Use como ejemplo una optimización del almacenamiento físico que no cambie las tablas lógicas y un cambio en las vistas que no altere la estructura interna.

7. **Explique las cuatro propiedades ACID usando el ejemplo de una transferencia bancaria.** ¿Qué podría ocurrir si no se garantizara cada propiedad?

8. **Escriba un texto personal de máximo 300 palabras en el que explique qué espera aprender o experimentar en el taller de Bases de Datos.** Esta reflexión debe expresar sus propias ideas.
